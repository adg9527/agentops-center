# 04 · 开发计划与阶段验收标准

每阶段交付：可运行成果 + 自动化测试 + 验收报告（`docs/phaseN-验收报告.md`）。

## 第一阶段：基础平台与 Agent 接入（当前）

| 交付 | 验收标准 |
|---|---|
| 工程骨架（backend FastAPI / frontend Vite+React+AntD） | 一条命令启动；`pytest` 通过 |
| 登录 / 首次初始化管理员 / RBAC | 未登录访问 API 返回 401；viewer 不能改 Agent |
| Dashboard | 指标全部来自 DB 聚合；未实现模块显示"第 N 阶段" |
| Agent 接入管理 | 增删改查、启停、连接测试、能力检测、执行历史、调用统计 |
| Adapter：Claude Code / OpenCode（真实）、Codex（未验证）、HTTP（通用） | 两个真实 Agent 完成真实任务并回传结果 |
| 基础任务发送 + 实时事件 | 任务状态流转、工具调用事件落库并实时推送、可取消 |
| 安全基线 | 密钥加密不回传、摘要脱敏、审计日志、超时/重试/并发 |

## 第二阶段：群聊与任务协作
群聊 CRUD、成员与角色、@Agent/@全体、人工分工、主控 Agent 自动拆分（LLM 输出结构化计划 JSON，平台校验后落为子任务）、Handoff 表与状态机、暂停/恢复/终止、审批（waiting_approval）、历史记录。
**验收**：同一群聊 ≥2 个真实 Agent；@指定执行；自动拆分出 ≥2 子任务并由不同 Agent 完成；生成结构化交接记录且被接收方确认。

## 第三阶段：执行监控与 Trace
全局实时事件流、多维筛选、Trace 瀑布图/时间线、单 Agent 轨迹、任务回放（按时间戳重放事件）、错误归类、日志检索。
**验收**：跨 Agent 的一个任务在同一 trace 下可视化；回放与原始事件一致。

## 第四阶段：资产管理
统一 Asset/AssetVersion；MCP（stdio/http 配置、`tools/list` 实测工具清单、启停→生成 Agent 运行时 `--mcp-config` 真正生效）、Skill（多文件夹、Skill Adapter 转换 Claude/OpenCode 格式）、Prompt（变量、发布、回滚）、Agent 配置版本化；diff 对比。
**验收**：停用 MCP 后新任务的 Agent 工具清单不含该 MCP（以 init 事件实测）。

## 第五阶段：自动化评测
数据集（CSV/JSON 导入、版本）、评分器（规则/匹配/JSON Schema/代码测试/DB 状态/工具调用/完成率/交接/LLM Judge/人工）、评测作业（并发/重复/超时/重试）、横向/纵向对比、ECharts 可视化。
**验收**：同一数据集对 2 个真实 Agent 实跑并出分；同一 Prompt 两版本回归对比。

## 第六阶段：报告中心
自动生成报告（快照）、在线查看、PDF（服务端渲染）、Excel（openpyxl）、JSON 导出、归档/版本/对比/检索。
**验收**：修改资产后历史报告不变；报告每个数字可点回原始评测记录。

## 第七阶段：平台完善
细粒度权限、审计检索、安全策略、Alembic 迁移、性能、异常恢复、Docker 部署（Web+DB 容器 + 宿主机 Agent Runner）、完整部署文档。
